pixelmon settings atlas

Every knob in the pixelmon GUI, the pixelmon command line, and the ComfyUI nodes they drive on the rtx render box, with ranges, defaults and a working example for each. Ranges are the limits the controls accept; where a narrower range is what actually looks good, it's called out. Settings marked ⚙ Advanced live in the GUI's rightmost tab.

Pipeline order on the server: prompt → CLIP text encode → (IPAdapter steering) → (ControlNet) → KSampler → VAE decode → PixelArtPalette node: smooth/downscale → palette lock + dither → despeckle → 1-px outlines → pixel-art angles → transparent → final nearest resize to the output size. Everything after the KSampler is post-processing, so palette, dither and cleanup never change what the model draws.
